# New Style Template

Create `references/styles/<style>.md` and `assets/<style>/`. `vars-light.css` is required;
`vars-dark.css`, `style.css`, `patterns.html`, and up to 1 MB of redistributable images are
optional.

Document recognition traits, variable rationale, color formula, font/size profile, preferred and
prohibited patterns, style-specific classes, and replaceable brand points. Brand assets that cannot
be redistributed remain user-supplied.

Validate every contract variable, direct browser preview of pattern HTML, both profiles when
present, no hard-coded brand color in core assets, and a representative cover/content/closing
sequence.
