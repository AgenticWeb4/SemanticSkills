# Generic Business Style

Use as the default fallback: quiet light surfaces, one restrained accent, neutral typography, modest
radius/shadow, and information-first layouts. Change the primary scheme through `--accent`, matching
`--accent-soft`, and `--table-head`; keep `--accent-2` as a cool neutral when the primary is warm.

Prefer summary, card grid, comparison, flow, matrix, and evidence patterns. Footer left holds page
number plus optional confidentiality; footer right is empty unless the user supplies a logo. Cover
uses `--bg-cover`; closing uses a plain thank-you and optional contact details.
