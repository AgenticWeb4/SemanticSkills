# Page Pattern Catalog

Fixed pages are cover first, agenda second, and thank-you last. Agenda entries exactly match the
current outline.

Choose the smallest pattern that expresses the relationship:

| Pattern                                           | Family/density        | Use                                        |
| ------------------------------------------------- | --------------------- | ------------------------------------------ |
| `chapter` / `question`                            | facade/light          | chapter opening or one real question       |
| `summary`                                         | claim/normal          | teaching goals or executive TL;DR          |
| `card-grid` / `dense-columns`                     | grid/normal–dense     | parallel points or inventory               |
| `kpi-band`                                        | grid/normal           | three to six measured outcomes with basis  |
| `image-text` / `compare`                          | split/normal          | one visual argument or AS-IS/TO-BE         |
| `pain-solution-value`                             | split/dense           | B2B problem, mechanism, value              |
| `flow` / `architecture`                           | flow/normal–dense     | process, timeline, or layered system       |
| `table-mix` / `matrix` / `decision`               | matrix/dense          | enumerations, capability status, decisions |
| `screenshot-pair` / `code-curve-metrics` / `case` | evidence/normal–dense | observed evidence and results              |

Do not repeat one visual family for three consecutive pages. Follow dense pages with light pages.
Use compound patterns rather than splitting coupled dimensions into shallow pages. Start from
`assets/core/skeletons.html` or style patterns and preserve the variable contract.
