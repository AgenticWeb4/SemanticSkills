# Seven-Stage Collaboration

Adapt to context: teaching uses problem → principle → practice → consolidation at roughly 1.5–2
minutes per page; reports lead with conclusion and use roughly half the available minutes as the
initial page budget; self-read material uses complete prose and no animation.

1. **Brief** — Ask audience, setting/duration, desired outcome, available evidence, style, and
   deliverable in one round. Summarize for confirmation.
2. **Outline** — Propose chapters, questions, minutes, and page counts. Save `<deck>.plan.md` only
   after confirmation.
3. **Patterns** — Map every outline item to a page pattern, visual family, and density.
4. **Draft** — Produce a per-page table and HTML using typed image placeholders.
5. **Revision** — Walk chapter by chapter and record page-level changes. Wait for “structure
   approved.”
6. **Final** — Replace placeholders, add teaching beats when applicable, clear debug overflow,
   verify numbers, and export PPTX if requested.
7. **Acceptance** — Apply final copy edits and deliver playback/editing notes and PPTX tier.

If told to proceed directly, offer disclosed defaults for the six brief dimensions in one answer and
ask only for corrections; confirmation gates remain. Default style is `generic`.

Every plan row names page number, label, one-sentence claim, pattern, family/density, image
type/source/aspect, and beats. Keep the plan synchronized with HTML after every revision.
